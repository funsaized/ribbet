# Tutorials

Follow a lesson from beginning to end. Each one gives you a small working result and checkpoints along the way.

| Lesson | You will build | Prerequisites |
| --- | --- | --- |
| [Your first pipeline](first-pipeline.md) | A sorted, projected record stream and an equivalent flow | Installed Ribbit; Bash or Git Bash |
| [Add a local model](local-model.md) | A feedback annotation pipeline, then a stronger-model summary | First pipeline; configured local endpoint and two profiles |
| [Make a reusable command](reusable-command.md) | A named brief command and a saved flow | A working semantic profile |

If you already know the basics and have a job to finish, use the [how-to guides](../how-to/index.md).
